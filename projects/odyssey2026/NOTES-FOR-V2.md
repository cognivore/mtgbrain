## 1. Rework the black "graveyard" archetype — it is NOT spell-storm
My v1 framing of BR as "hellbent graveyard-**storm**" was wrong. The intended deck is a **slow,
grindy discard-matters / threshold engine**, not a Tendrils/storm combo. Build it around:
- **Monument to Endurance** (discard payoff engine) — add it (verify in DB; it's in the `wary` list).
- **Black enchantments that trigger when you discard** — Faith of the Devoted (already in), Waste Not,
  Bone Miser, Sangromancer, Necrogen Mists, Oppression-style; find the full set in the DB.
- **Flashback spells** (graveyard value, slow inevitability) — push these harder across B (and R/G).
- **Threshold** as the connective enabler.
- It is "way slower" — a value grind, not a kill-turn. Tune its payoffs accordingly.

## 2. Black should go HARD on threshold creatures
Lean black's creature base further into **threshold** bodies (it already runs many — Boneshard
Slasher, Childhood Horror, Treacherous Werewolf, Mortivore, etc.; go deeper from the `/odysseyblock`
pool). Threshold is black's main "the graveyard filling up makes my dudes good" axis.

coin-flip with only a storm-*lite* finish. Re-word the BR/UR primer entries so "graveyard grind" and
"spell-storm" aren't conflated. Example UBr storm decklist already drafted (in chat) — fold into the
deck-proofs doc.
